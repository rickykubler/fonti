# fonti — project notes for Claude

Local-first RAG for Italian documents with verifiable citations. Personal open-source project:
never use employer code, data, prompts or tools here; test data must be public or synthetic.

## Commands

PowerShell 5.1 has no `&&`: run commands one per line.

- Setup (NVIDIA GPU, this machine): `uv sync --extra gpu`
- Setup (CPU only, also CI): `uv sync --extra cpu`
- Fast tests (what CI runs): `uv run pytest`
- Slow tests (real models from the HF cache, Docling, Ollama): `uv run pytest -m slow`
- Lint: `uv run ruff check .`
- Format check: `uv run ruff format --check .`
- Types: `uv run mypy`
- All hooks: `uv run pre-commit run --all-files`
- CLI: `uv run fonti --help` (`ingest`, `ask`, `docs`, `remove`, `reindex`, `models pull`, `serve`)
- Web UI: `uv run fonti serve --open` (127.0.0.1:8000 only)
- Evaluation: `uv run fonti eval corpus`, `uv run fonti eval check`, then
  `uv run fonti --config eval/configs/<name>.toml eval run --dataset main --label <name>`
  (`--retrieval-only` for fast runs); reports go to `eval/reports/`
- Docling extra: `uv sync --extra gpu --extra docling`
- Hugging Face downloads may hang with Xet on this network: retry or set `HF_HUB_DISABLE_XET=1`

Plain `uv sync` drops the torch extra: always pass `--extra cpu` or `--extra gpu`.
Tests run with `HF_HUB_OFFLINE=1`, so download models once before running slow tests.

## Architecture

Status of each part is in `docs/ROADMAP.md`.

- `ingest/` parse → clean → chunk. Pure functions, no storage.
- `index/store.py` SQLite: documents, pages, chunks, FTS5 index, vectors. The only module with SQL.
- `ml/` embedder and reranker (sentence-transformers), loaded lazily.
- `retrieval/` BM25 + dense search → RRF fusion → rerank → relevance gate.
- `generation/` LLM clients (Ollama native API by default, OpenAI-compatible; local-only guard), Italian prompts,
  citation alignment and abstention.
- `service.py` `ingest()` / `ask()`: the only API used by `cli.py`, `web/` and `evaluation/`.

## Conventions

- User-facing strings and LLM prompts are Italian; code, comments and docs are English.
- Chunks store document-level character offsets; pages are derived from offsets.
- Citation passages are extracted verbatim from the source, never generated by the LLM.
- Network access only in `generation/llm.py` (loopback unless `allow_remote`) and model downloads.
  Tests block non-loopback sockets.
- Eval evidence is identified by quote text, not by chunk id, so chunking can change freely.
- Windows first: `pathlib` everywhere, tooling scripts in Python, no bash-only scripts.
- Tests that need real models, Docling or Ollama are marked `slow` and excluded by default;
  fast tests use `HashingEmbedder` (`embedding.model = "hashing"`) and `tests/fakes.FakeChat`.
- User-facing errors subclass `fonti.errors.FontiError`; the CLI prints them without traceback.
- Never write `\uXXXX` escapes through the editor tools (they get decoded into raw characters);
  use `\N{NAME}` or `chr()` instead.

## Path-scoped rules and skills

- `.claude/rules/` loads extra rules when editing matching paths: `retrieval-quality.md`
  (eval before/after), `web.md` (web UI safety and states), `untrusted-content.md`
  (prompt injection, SQL, hostile files).
- Skill `eval-compare`: baseline vs candidate eval with metric deltas
  (`.claude/skills/eval-compare/compare.py`).

## Do not

- Add RAG frameworks (LangChain, LlamaIndex, Haystack) or vector DB servers.
- Add AGPL/GPL dependencies (PyMuPDF, Marker, MinerU, Surya) or libraries with telemetry on by
  default (Gradio, Streamlit, Chroma).
- Weaken the local-only guard or make a cloud provider the default.
- Edit golden answers or evidence to make an evaluation pass.
- Commit PDFs, downloaded corpora, indexes, `fonti.toml` or `.env`.
- Log document text or questions above DEBUG level.
